<h1 align="center">🎓 QuizVerse – Interactive Online MCQ Examination System</h1>

<p align="center">
  A modern, real-time, and user-friendly MCQ exam platform built with <b>Laravel</b>, <b>Livewire</b>, <b>MySQL</b>, <b>TailwindCSS</b>, and <b>Bootstrap</b> Admin Panel.
  <br><br>
  Designed for <b>students</b>, <b>teachers</b>, and <b>organizations</b> to conduct exams seamlessly with instant evaluation and performance tracking.
</p>

---

## 🚀 Features

### 👨‍🎓 User Features
- 📝 Take MCQ quizzes  
- ⏱ Real-time exam with countdown timer  
- ⚡ Livewire-powered interactive UI (no reload)  
- 📊 Instant score after submission  
- 🔍 Review answers  
- 📜 View past performances  
- 📱 Fully mobile responsive  

### 🛠 Admin Features
- 📚 Manage categories & question bank  
- ❓ Add MCQs with multiple options  
- 🧪 Create quizzes with time & difficulty  
- 👥 Manage users & roles  
- 📈 Admin dashboard with statistics  
- 🗂 Monitor exam attempts & results  

### 🌟 System Highlights
- 💨 Smooth UI powered by Tailwind  
- 🏗 Laravel MVC architecture  
- 🧵 Real-time Livewire components  
- 🔐 Secure authentication - role based authentication & authorization system
- 🗄 MySQL-based scalable structure
